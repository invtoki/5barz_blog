# 5Barz Blog

A React blog app where users can browse, create, and view blog posts.

**Live demo:** https://invtoki.github.io/5barz_blog/

## Tech
- React, React Router
- Firebase Realtime Database
- Cloudinary (image uploads)
- Deployed on GitHub Pages

## Features
- Blog list and single post pages
- Add new posts
- Delete posts
- Responsive layout

## Run locally
npm install
npm start
